# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/networkdefendersecurity/zta/security/advisories/new)
(**Security** tab → **Report a vulnerability**).

Do **not** open a public issue for security problems.

You can expect an acknowledgment within 7 days. Please include reproduction
steps and the affected version (`zta` release tag or commit).

## Supported versions

Only the latest release receives security fixes.

## Known gaps

`zta` documents its known enforcement gaps openly — see
[security-audit/AUDIT-REPORT.md](security-audit/AUDIT-REPORT.md) and the
redteam kit in [redteam/](redteam/). A report about an already-documented gap
is still welcome if it changes the severity or shows a new exploitation path.
